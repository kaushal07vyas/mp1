How I think about engineering

Revive before rewrite

Legacy systems carry institutional knowledge. I would rather modernize what exists than start from scratch, which is how I delivered the NGS project after four years of stalled attempts.

Measure the bottleneck

Before optimizing anything, I find the constraint. At TCS, profiling query paths led to a 60% improvement in response times on dashboards processing 500+ GB daily.

Automate the repetitive

Manual work compounds into wasted hours. Automating the OTR scheduler at TCS gave back 20 hours of manual work per week, freeing the team for higher-value tasks.

Make it runnable locally

If developers cannot run the system on their own machine, iteration slows down. At FedEx, I created the first-ever local dev setup for ERMA, removing dependency on shared environments.
